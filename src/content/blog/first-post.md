このサイトは [Astro](https://astro.build) の静的出力で作られており、サーバーサイドの実行環境を必要としません。

## 各ページについて

- **Projects**: GitHub の公開リポジトリを、ビルド時に GitHub REST API から取得して表示します。
- **Research Blog**: このページのように、Markdown で書いた記事を Astro Content Collections で管理します。
- **Papers**: 論文・ポスター・研究成果を掲載する場所です。掲載できるものが用意でき次第、追加します。

## 今後書きたいこと

研究日誌、論文解説、実験結果などを、少しずつ載せていく予定です。
