I started using Grok Bot on the Cursor Pro plan. Lately, several companies have been releasing similar tools under names like "Cowork," which makes it hard to tell their features and design philosophies apart — but what's novel about Grok Bot is that each user gets their own VM assigned.

For now, I just connected to the VM.
