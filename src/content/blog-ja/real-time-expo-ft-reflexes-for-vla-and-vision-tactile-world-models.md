2026年9月16日に公開された論文「Reinforcement Learning for Real-Time Vision-Language-Action Policies」を読みました。

この研究の面白いところは、**大規模なVLAにすべての判断を任せるのではなく、素早く反応する小さな方策を組み合わせ、強化学習によってロボットの動作を改善する**という発想です。

私が取り組んでいる「Vision-Tactile JEPA World Models for Failure-Aware Long-Horizon Robotic Manipulation」とも関係が深く、特に失敗予測から動作修正につなげる仕組みを考えるうえで参考になります。

今回は、論文の技術的なポイントを整理しながら、自分の修士研究にどう活かせるかを考えてみます。

-   論文：[https://arxiv.org/pdf/2609.18207](https://arxiv.org/pdf/2609.18207)
-   プロジェクト：[https://pd-perry.github.io/real-time-expo-ft/](https://pd-perry.github.io/real-time-expo-ft/)

## 1\. VLAの課題は「考えている間に世界が変わる」こと

VLAは、カメラ画像や言語指示からロボットの行動を生成します。しかし、モデルが大きくなるほど推論に時間がかかります。

例えば、ロボットが動いている物体をつかもうとしたとき、VLAが画像を認識して行動を生成している間にも、物体は移動しています。

つまり、行動を実行する時点では、その行動を考えたときの観測情報が古くなっているのです。

従来のReal-Time Chunking（RTC）は、現在の行動を実行しながら次の行動列を非同期に生成することで、動作の途切れを減らしてきました。

しかし、次の行動列が生成されるまでに生じた環境の変化に、十分対応できるとは限りません。

そこで本研究では、**VLAによる行動生成と、最新の観測に基づく行動修正を分離する**というアプローチを取っています。

## 2\. Real-Time EXPO-FTの仕組み

提案手法のReal-Time EXPO-FTは、事前学習済みのVLAに、小規模な編集方策（Edit Policy）と価値関数（Q-function）を組み合わせた構成です。

処理は大きく3つに分かれます。

### STEP 1：大規模VLAによる行動生成

少し前の観測情報から、複数のAction Chunk（行動列）を非同期で生成します。

### STEP 2：Edit Policyによる行動修正

実行直前の最新の観測を確認し、VLAが生成した行動候補に小さな修正を加えます。

### STEP 3：Q-functionによる行動選択

元の候補と修正後の候補を評価し、Q値が最も高い行動列を実行します。

重要なのは、Edit Policyが単純な補正ルールではなく、**強化学習によって改善される方策**であることです。

編集方策はQ値の高い行動へと修正するよう学習し、Q-functionは実際の試行結果を利用した時間差学習（TD学習）で更新されます。

一方、大規模VLAは行動データを使った模倣学習によってファインチューニングされます。実機実験では、ベースとなるVLAにπ0.5を使用しています。

この設計は、人間でいえば、計画を立てる役割と、とっさの反応を行う役割を分けるようなものだと感じました。

VLAの推論そのものを高速化するのではなく、遅延があることを前提として、実行直前に判断を修正できる仕組みを作っているのです。

## 3\. 実験結果：実機で平均成功率42%から97%へ

論文では、動的な環境への対応能力を確認するため、4種類の実機タスクで評価しています。

| タスク | 内容 |
| --- | --- |
| Dynamic Picking | 回転台で動く物体を把持する |
| Ball Balancing | プレート上のボールを安定させる |
| Object Passing | 別のロボットから動く物体を受け取る |
| Soccer Kicking | 動く対象に合わせてボールを蹴る |

各タスクのオンライン学習に用いるロボットの稼働データは最大10分間です。学習用の計算時間や、事前のデモ収集まで含めて10分という意味ではありません。

実機評価の結果は次のとおりです。

| タスク | 学習前（SFT） | Real-Time EXPO-FT |
| --- | --- | --- |
| Dynamic Picking | 19/30 | 30/30 |
| Ball Balancing | 8/30 | 28/30 |
| Object Passing | 10/30 | 30/30 |
| Soccer Kicking | 13/30 | 28/30 |
| 平均成功率 | 約42% | 約97% |

※論文Table Iより。各タスク30試行の評価結果。

特に注目したいのは、事前学習済みVLAを使いながら、少量の実機経験で動的なタスクへの対応を改善できている点です。

なお、論文にはKinetixの10タスクでのシミュレーション評価もありますが、こちらはVLAではなく状態ベクトルを入力するFlow Matching方策を使用しています。

実機でのVLA評価とは区別する必要があります。

## 4\. 私の研究との関係：失敗を予測し、回避するVLAへ

ここからは、私の修士研究との関係を考えてみます。

研究テーマは、以下のとおりです。

**Vision-Tactile JEPA World Models for Failure-Aware Long-Horizon Robotic Manipulation**

日本語では「失敗認識型の長期ロボットマニピュレーションに向けた視覚・触覚統合JEPA世界モデル」です。

私の研究では、RGB画像やDepth、触覚、ロボットの状態を統合し、将来の状態を予測するWorld Modelを構築することを目指しています。

特に重要なのが、把持の失敗や物体の滑りを事前に予測し、それを行動修正や再計画につなげることです。

Real-Time EXPO-FTと比較すると、両者の目的には重なる部分がありますが、アプローチは異なります。

| 観点 | Real-Time EXPO-FT | 私の研究 |
| --- | --- | --- |
| 主な目的 | 推論遅延下でのリアルタイム制御 | 失敗予測と長期タスクの改善 |
| 観測 | RGB・ロボット状態 | RGB・Depth・触覚・ロボット状態 |
| 中核技術 | VLA・Edit Policy・Q-function | VLA・JEPA World Model |
| 将来予測 | Q値による行動価値の推定 | 将来の潜在状態の予測 |
| 行動改善 | 強化学習による行動修正 | 失敗予測に基づく行動修正・再計画 |
| 時間的な対象 | 短い行動列のリアルタイム制御 | 複数の操作段階にまたがる長期タスク |

Real-Time EXPO-FTは、最新の観測を使って行動を修正します。一方、私の研究では、将来の状態まで予測して失敗を回避することを目指します。

この違いをうまく活かせれば、単なるリアルタイム制御だけではなく、**失敗の兆候を捉えて、失敗する前に行動を修正できるロボット**につながると考えています。

ただし、Real-Time EXPO-FTが将来情報をまったく扱わないわけではありません。

Q-functionは将来の累積報酬を推定します。JEPAとの違いは、行動の価値を推定するのか、将来の潜在状態そのものを予測するのか、という点にあります。

## 5\. JEPA World Modelと強化学習を組み合わせる

今回の論文から得られた研究アイデアは、JEPA World Modelを行動修正に利用することです。

例えば、ロボットが物体を持ち上げる場面を考えます。

VLAが「物体を把持して持ち上げる」という行動を生成したとします。

しかし、指先の触覚センサから物体が滑り始めていることがわかった場合、そのまま持ち上げると落下する可能性があります。

そこで、触覚情報とWorld Modelによる将来予測を使って、実行する行動を修正できないでしょうか。

### 提案する研究アーキテクチャ

```
RGB / Depth / Tactile / Robot State / Language
                     |
          +----------+----------+
          |                     |
          v                     v
         VLA          Vision-Tactile JEPA
          |                     |
     行動候補生成         将来の潜在状態予測
          |                     |
          |             接触状態・滑り予測
          |                     |
          +----------+----------+
                     |
                     v
          Failure-Aware Edit Policy
                     |
              行動候補の修正
                     |
                     v
         Action Selection / Replanning
                     |
                     v
               Robot Execution
                     |
                     v
               新たな観測・学習
```

※論文の構成を参考にした独自の研究構想。論文中で検証されたアーキテクチャではありません。

ここでJEPAを単なる特徴抽出器として使うだけでは、研究としての面白さが十分に出ません。

JEPAが予測した将来の接触状態や滑りの兆候を、Edit Policyの入力、あるいは行動候補の評価に活用することが重要だと考えています。

### World Modelによる失敗リスクを考慮した行動選択

例えば、World Modelが将来の潜在状態を予測し、その予測から失敗確率を推定できれば、次のような行動選択が考えられます。

```
a* = argmax_a [ Q(s, a) - λ × P_fail(s, a) ]
```

この式は、**行動の価値が高く、かつ失敗する可能性が低い行動を選択する**という意味です。

各記号は以下を表します。

| 記号 | 意味 |
| --- | --- |
| a\* | 選択する行動 |
| argmax\_a | 評価値が最大となる行動aを求める |
| Q(s, a) | 状態sで行動aを実行した場合の期待累積報酬 |
| P\_fail(s, a) | World Modelの予測から推定する失敗確率 |
| λ | 失敗リスクに対する重み |

例えば、次の2つの行動候補があったとします。

-   行動A：素早く物体を持ち上げる
-   行動B：把持力を調整してから持ち上げる

それぞれの評価値を仮に次のように設定します。

```
λ = 2.0

行動A：
Q(s, A)      = 0.9
P_fail(s, A) = 0.4

評価値 = 0.9 - 2.0 × 0.4
       = 0.1

行動B：
Q(s, B)      = 0.7
P_fail(s, B) = 0.1

評価値 = 0.7 - 2.0 × 0.1
       = 0.5
```

この場合、行動AのQ値は高いものの、失敗リスクを考慮すると行動Bが選択されます。

つまり、World Modelが将来の滑りを予測できれば、VLAが生成した行動を実行する前に、より安全な行動へ修正できる可能性があります。

ただし、これはあくまで研究アイデアを説明するための簡略化した計算例です。

Q-functionがすでに失敗による損失を学習している場合、失敗リスクを別途減算すると二重に評価してしまう可能性があります。

実際の研究では、Q-functionと失敗予測をどのように統合するかについても検証する必要があります。

## 6\. 修士研究で検証したいこと

この論文を参考にするなら、まずは長期タスク全体を強化学習するよりも、**失敗予測を使った局所的な行動修正が本当に効果を持つのか**を確認したいと思います。

例えば、SO-101を使った把持・持ち上げ・運搬・配置のタスクで、視覚のみの場合と触覚を追加した場合を比較します。

そのうえで、World Modelの予測を使わないEdit Policyと、予測を使うFailure-Aware Edit Policyを比較すれば、JEPAによる将来予測の価値を切り分けられそうです。

評価指標としては、タスク成功率だけでなく、失敗の予測精度、失敗からの回復率、再計画回数、行動修正の遅延なども考えられます。

実機での強化学習は安全性やデータ収集コストの課題があるため、まずはシミュレーションや模倣学習で検証し、限定的な実機タスクへ展開する方針が現実的だと思います。

また、Real-Time EXPO-FT自体は長期タスクの階層的な計画や、触覚を利用した接触予測を直接検証しているわけではありません。

これらを自分の研究でどう扱うかが、重要な検討事項になります。

## 7\. まとめ：VLAの反射神経とWorld Modelによる予測

Real-Time EXPO-FTを読んで、VLAの行動生成、World Modelの将来予測、強化学習による行動改善を、必ずしも一つの巨大なモデルにまとめる必要はないと感じました。

大規模VLAが行動を生成し、小規模な方策が最新の状態に素早く反応する。その間にWorld Modelによる失敗予測を組み込めれば、より先を見据えた行動修正ができるかもしれません。

私の研究では、JEPAによる視覚・触覚の統合表現と将来予測を中心に据えながら、今回の論文で示されたEdit Policyの考え方を参考にしていきたいと思います。

最終的には、失敗してからやり直すだけでなく、失敗の兆候を予測して行動を修正し、長期タスクを継続できるロボットを目指したいです。
